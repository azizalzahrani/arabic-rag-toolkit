# معمارية نظام RAG العربي

## نظرة عامة

أدوات RAG العربية هي نظام شامل لبناء تطبيقات Retrieval-Augmented Generation (RAG) متخصصة في اللغة العربية. يجمع النظام بين معالجة اللغة الطبيعية المتقدمة والتعلم العميق والبحث الذكي.

## المكونات الرئيسية

### 1. معالج النصوص العربية (Preprocessor)

**الملف**: `arabic_rag/preprocessor.py`

يقوم بمعالجة وتطبيع النصوص العربية:

- **إزالة التشكيل**: إزالة الفتحات والكسرات والضمات والسكون
- **توحيد الألف**: توحيد جميع أشكال الألف (أ، إ، آ) إلى ا
- **توحيد الياء والهاء**: معالجة أشكال مختلفة من الأحرف
- **إزالة التطويل**: إزالة حرف التطويل الزائد
- **معالجة المسافات**: إزالة المسافات الزائدة والتنسيق

**الاستخدام الأساسي**:
```python
preprocessor = ArabicTextPreprocessor()
normalized_text = preprocessor.normalize("اَلنَّصُ العَرَبِي")
```

### 2. معقم النصوص (Chunker)

**الملف**: `arabic_rag/chunker.py`

يقطع النصوص الطويلة إلى أجزاء قابلة للمعالجة مع احترام سلامة الجمل والكلمات:

- **تقطيع ذكي**: يحاول تقسيم النص عند حدود الجمل
- **معالجة الجمل الطويلة**: قطع الجمل الأطول من الحد المحدد
- **تداخل الأجزاء**: إضافة تداخل بين الأجزاء للحفاظ على السياق
- **احترام الفقرات**: الحفاظ على بنية الفقرات الأصلية

**الاستخدام الأساسي**:
```python
chunker = ArabicTextChunker(chunk_size=300, chunk_overlap=50)
chunks = chunker.chunk(long_text)
```

### 3. نموذج التضمين (Embeddings)

**الملف**: `arabic_rag/embeddings.py`

يحول النصوص إلى متجهات رقمية:

- **دعم عدة نماذج**: يدعم نماذج التضمين المختلفة
- **البحث عن التشابه**: حساب درجات التشابه بين النصوص
- **تطبيع المتجهات**: تطبيع المتجهات إلى طول واحد
- **معالجة دفعية**: معالجة عدة نصوص في وقت واحد

**الاستخدام الأساسي**:
```python
embeddings = ArabicEmbeddings()
vector = embeddings.embed_text("نص عربي")
similarity = embeddings.similarity("كتب", "كتابة")
```

### 4. محرك البحث (Retriever)

**الملف**: `arabic_rag/retriever.py`

يبحث عن أكثر المستندات تشابهاً مع الاستعلام:

- **دعم عدة قواعد بيانات**: FAISS و ChromaDB
- **البحث السريع**: بحث فعال في قواعد البيانات الكبيرة
- **تصفية النتائج**: تطبيق حد أدنى للتشابه

**الاستخدام الأساسي**:
```python
retriever = ArabicRetriever()
retriever.add_documents(documents)
results = retriever.retrieve("السؤال", top_k=5)
```

### 5. منشئ الإجابات (Generator)

**الملف**: `arabic_rag/generator.py`

يولد الإجابات باستخدام نماذج اللغة:

- **دعم عدة مزودي الخدمات**: OpenAI و Anthropic والنماذج المحلية
- **تحسين الإجابات**: تحسين الصياغة والاستكمال
- **إضافة المراجع**: ربط الإجابات بالمصادر

**الاستخدام الأساسي**:
```python
generator = ArabicResponseGenerator()
answer = generator.generate_answer(question, context=context)
```

### 6. خط الأنابيب المتكامل (Pipeline)

**الملف**: `arabic_rag/pipeline.py`

يجمع جميع المكونات في خط أنابيب واحد متكامل:

- **تسلسل العمليات**: معالجة النصوص → التقطيع → التضمين → البحث → التوليد
- **إدارة المستندات**: إضافة وحفظ وتحميل المستندات
- **الاستعلام المتقدم**: دعم استعلامات معقدة

**الاستخدام الأساسي**:
```python
pipeline = ArabicRAGPipeline()
pipeline.add_documents(documents)
answer = pipeline.query(question)
```

## وكلاء CrewAI (Agents)

**الملف**: `arabic_rag/agents/`

فريق من الوكلاء المتخصصة:

### وكيل البحث (Research Agent)
- البحث عن المستندات ذات الصلة
- تحليل الاستعلام
- إدارة سجل البحث

### وكيل التحقق (Validator Agent)
- التحقق من صلة المستندات
- تقييم جودة الإجابات
- تصفية النتائج الضعيفة

### وكيل الكتابة (Writer Agent)
- تحسين صياغة الإجابات
- إضافة الاستشهادات
- التحقق من جودة النص العربي

### فريق العمل (Multi-Agent Crew)
- تنسيق عمل الوكلاء الثلاثة
- تنفيذ مهام معقدة
- إدارة سير العمل

**الاستخدام الأساسي**:
```python
crew = setup_crew(retriever=my_retriever)
result = crew.execute_task("المهمة المطلوبة")
```

## الأدوات المساعدة (Utilities)

**الملف**: `arabic_rag/utils/arabic_utils.py`

دوال مساعدة متخصصة في اللغة العربية:

- `is_arabic_text()`: التحقق من وجود نصوص عربية
- `count_arabic_words()`: عد الكلمات العربية
- `extract_numbers()`: استخراج الأرقام
- `get_text_statistics()`: الحصول على إحصائيات النص

## تدفق البيانات

### 1. المرحلة الأولى: إضافة المستندات

```
المستندات الخام
    ↓
[معالج النصوص] → تطبيع النصوص
    ↓
[معقم النصوص] → تقطيع إلى أجزاء
    ↓
[نموذج التضمين] → تحويل إلى متجهات
    ↓
[قاعدة البيانات المتجهة] → تخزين الأجزاء والمتجهات
```

### 2. المرحلة الثانية: الاستعلام والإجابة

```
السؤال من المستخدم
    ↓
[معالج النصوص] → تطبيع السؤال
    ↓
[نموذج التضمين] → تحويل إلى متجه
    ↓
[محرك البحث] → البحث عن أجزاء متشابهة
    ↓
[وكيل التحقق] → تصفية النتائج الضعيفة
    ↓
[منشئ الإجابات] → توليد الإجابة
    ↓
[وكيل الكتابة] → تحسين الصياغة
    ↓
الإجابة النهائية
```

## المعايير المقيسة

### جودة التضمين
- **Similarity Score**: درجة التشابه بين النصوص (0-1)
- **Dimensionality**: عدد أبعاد المتجه (عادة 384 أو 768)

### كفاءة البحث
- **Retrieval Accuracy**: دقة استرجاع المستندات المتعلقة
- **Response Time**: وقت الاستجابة
- **Scalability**: القدرة على التعامل مع أعداد كبيرة من المستندات

### جودة الإجابات
- **Relevance**: ملاءمة الإجابة للسؤال
- **Coherence**: اتساق واتصال الإجابة
- **Completeness**: استكمالية الإجابة

## التوسع والتطوير المستقبلي

### المخطط المستقبلي
1. دعم اللهجات العربية (مصرية، شامية، خليجية)
2. نماذج تضمين متخصصة مدربة على النصوص العربية
3. دعم الملفات متعددة اللغات
4. واجهة ويب تفاعلية
5. نظام إدارة معرفة متقدم

## أفضل الممارسات

1. **استخدام التطبيع المناسب**: تحديد التطبيع المناسب حسب نوع النص
2. **حجم الأجزاء المناسب**: اختيار حجم الأجزاء المناسب (عادة 300-500 حرف)
3. **نموذج التضمين**: استخدام نموذج مدرب على النصوص العربية
4. **إدارة قاعدة البيانات**: تنظيم وفهرسة المستندات بشكل فعال
5. **التحقق من الجودة**: التحقق من جودة الإجابات بشكل دوري
